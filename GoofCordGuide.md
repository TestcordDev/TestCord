You can install Testcord on Goofcord. This is preferred for people on MacOS, as there is no official installer.
<br>
<br>
This guide does work on the following other Operating Systems: Linux and Windows 10/11.

## How to Install?
1. Install [Goofcord](https://github.com/Milkshiift/GoofCord/releases)
2. Go into Settings > Goofcord Settings > Assets
3. Replace the External Asset named "Vencord" with the following:
    - https://github.com/TestcordDev/TestCord/releases/download/latest/browser.js 
4. Replace the External Asset named "VencordStyles" with the following:
    - https://github.com/TestcordDev/TestCord/releases/download/latest/browser.css

Restart, and now you have Testcord!
