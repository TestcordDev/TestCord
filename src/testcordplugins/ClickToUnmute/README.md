# Click to unmute

DavidHiFi's maintained fork of [Kurtzon Audio's ClickToUnmute](https://github.com/kurtzonaudio/kurtcord-plugins). Click a locally muted voice member's mute icon to unmute them. The patch captures the row's user instead of relying on fixed minified variable names.

Original author: [Kurtzon Audio](https://discord.com/users/1552878708732469258). Maintainer: DavidHiFi. Both remain in the plugin author list. MIT licensed.

Copy this folder to `src/userplugins/ClickToUnmute`, replacing the previous source folder, then build your client. Keep the plugin name to preserve settings. Load the rebuilt client after your call ends.
